# Minigame 1
## Devlog
I think these three are quite similar to cars. Components refer to the individual parts, such as the headlights, steering wheel, and dashboard. The game object is the car itself, which is composed of various components. The scene could be a garage, with many different vehicles inside. In my game, PlayerCapsule is a game object that controls the movement and jumping of the character. In the Main Scene, there are game objects, gold coins, traps and other game elements.
